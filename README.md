# Micros Camiri · Líneas

Edición solo Líneas de la app Micros Camiri: recorridos, paradas, fotos de los micros, calles por donde pasa cada línea y lugares cercanos.

- Página estática: no necesita servidor ni base de datos.
- Se genera desde la app completa (repositorio `micros-camiri-completo`) con `_proyecto/herramientas/hacer_edicion_lineas.py`: no se edita a mano aquí.
