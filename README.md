# Micros Camiri

Aplicación web (PWA) con las rutas, distancias y tiempos de las líneas de micros de Camiri.

- Página estática: no necesita servidor ni base de datos.
- Las rutas están en `rutas_datos.js`. Para actualizarlas, se reemplaza ese archivo.
- Las fotos de las paradas están en `fotos/`.
- Se puede instalar en el celular y funciona con poca señal (service worker en `sw.js`).
